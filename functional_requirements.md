### 4.2.1 Requirement Specification

**Functional Requirement**

The functional requirements this application include:

**General**

1. The application shall allow users to register an account with a selected role (dementia patient or caregiver).
2. The application shall allow users to log in and log out using authenticated email and password credentials.
3. The application shall allow users to view a personalized dashboard showing their daily tasks and medication schedules.
4. The application shall allow users to mark a task or medication as completed, and revert it back to pending.
5. The application shall automatically mark a task as missed if it is not completed by its due date and time.
6. The application shall allow users to receive local push notification reminders for scheduled tasks and medications.
7. The application shall allow users to adjust the application's font size for accessibility.
8. The application shall display navigation options in the side menu according to the logged-in user's role.

**Dementia Patients**

1. The application shall allow dementia patients to participate in cognitive exercises, including a category naming game and a memory matching (card-matching) game.
2. The application shall allow dementia patients to earn points by logging in daily and by completing tasks, medications, and cognitive games.
3. The application shall allow dementia patients to view their daily login streak, total points, and level.
4. The application shall allow dementia patients to view their own complete task history and filter it by status (completed, missed).
5. The application shall allow dementia patients to update the status of a past task, or delete it.

**Caregiver**

1. The application shall allow caregivers to add dementia patient accounts and link them under their care.
2. The application shall allow caregivers to create, edit, and delete tasks and medication schedules for their patients.
3. The application shall allow caregivers to assign a task to a specific patient, with a category, due date, and reminder.
4. The application shall allow caregivers to view patient task status (pending, completed, missed), grouped by patient.
5. The application shall allow caregivers to view a specific patient's complete task history and filter it by status.
6. The application shall allow caregivers to edit a patient's name and send a password reset email to a patient.
7. The application shall allow caregivers to unlink (remove) a patient from their care.
8. The application shall allow caregivers to manage multiple patient accounts from a single caregiver account.
